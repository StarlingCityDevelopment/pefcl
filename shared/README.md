# Shared Code

This directory contains code and types that are shared across different parts of the project (Client, Server, and Web).

## Directory Structure

- **`/hooks`**: (If present) Shared logic for both UI and Game client.
- **`/utils`**: General utility functions that are environment-agnostic.
- **`constants.ts`**: Shared constants like resource names, event identifiers, and default values.

Using shared code helps maintain consistency and prevents duplication of logic between the frontend and the backend.
